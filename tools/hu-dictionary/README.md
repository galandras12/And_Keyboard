# Hungarian dictionary builder

`build_hu_dict.py` builds a Hungarian suggestion/correction dictionary (`main_hu.dict`) from

1. the Hungarian **Hunspell** dictionary `hu_HU` (word list and affix rules), expanded with `unmunch`, and
2. a free **word frequency list**, used to rank the words.

## Usage

```sh
sudo apt install hunspell-tools      # provides `unmunch`; Java is needed as well
python3 tools/hu-dictionary/build_hu_dict.py
# -> tools/hu-dictionary/out/main_hu.combined   (AOSP wordlist, text)
# -> tools/hu-dictionary/out/main_hu.dict       (loadable by the keyboard)
```

Load the `.dict` file on the phone via Settings → Languages & layouts → Hungarian → Dictionary → add
(or the `+` button) and choose `main_hu.dict`. Nothing is downloaded by the keyboard itself.

Useful options: `--out-dir`, `--work-dir`, `--min-count N` (ignore rarer corpus words, default 3),
`--min-unknown-count N` (also add frequent corpus words Hunspell does not know; off by default because
the corpus contains typos and foreign words), `--skip-dict` (no Java needed, only the `.combined` file).
Downloaded files are pinned to exact commits and verified by SHA-256.

## How it works

1. **Download** the pinned sources (see below) into `work/`.
2. **Resolve affix aliases.** `hu_HU` stores flags as numeric aliases (`AF` table), which `unmunch` cannot
   read. The script replaces them by the literal flags (`hu_flat.aff`, `hu_flat.dic`).
3. **`unmunch`** expands stems with all prefix/suffix combinations. That produces ~350 million forms
   (about 10 GB of text), many of them implausible, so the output is streamed through a filter instead of
   being stored. A generated form is kept if it occurs in the frequency list (case-insensitively; capitalized
   forms are kept for proper nouns). All stems are kept as well. Stems that Hunspell marks as forbidden,
   affix-only, compound-only or no-suggest are left out as bare words.
4. **Frequencies.** `f = 1 + 254 * ln(count) / ln(max_count)` (1..255); words missing from the corpus get `f=1`.
   A capitalized form gets `f=1` if its lowercase form is also in the list.
5. **Compile** the `.combined` list with `dicttool_aosp.jar makedict`.

Result of the pinned build: 97,581 stems, 371.8 million generated forms, 444,398 words in the list, a 2.7 MB `main_hu.dict`
(about 3 minutes on 4 cores).

Known limitations: compound words (Hunspell `COMPOUNDRULE`) are not generated by `unmunch`, and valid
inflected forms that never occur in the corpus are missing. No next-word (bigram) data is produced.
